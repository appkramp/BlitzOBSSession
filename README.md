# Blitz Session Stats

Плагин для **OBS Studio 32+** (Windows и macOS), который выводит на стрим статистику
**World of Tanks Blitz** за выбранный период — сессию стримера, обновляемую в реальном
времени.

По каждому танку: иконка класса, уровень, название, бои, процент побед, средний урон,
точность, выживаемость, фраги — и строка итогов. Данные приходят с сервера
`stats.appkramp.com` сразу после того, как он их получил.

## Доступ

Доступ **платный**: плагин работает по ключу, который выдаёт мобильное приложение
подписчикам. Подписка на плагин оформляется в приложении.

> Сейчас подписка находится в **тестировании**.

## Возможности

- статистика за сегодня или с выбранной даты и времени;
- все танки, выбранные танки или только итоги; группировка по уровню или классу;
- сортировка по любой колонке, свой порядок и набор колонок;
- оформление: шрифт, цвета колонок, цвет по значению (например, процент побед),
  полупрозрачные блоки строк, рамки, отступы;
- ник аккаунта над таблицей и логотип рядом с ней;
- статистика **нескольких аккаунтов** по одному ключу — каждая копия на сцене отдельно,
  в оформлении основного источника;
- русский, английский и украинский языки.

## Установка

Установщики — на странице [Releases](https://github.com/appkramp/BlitzOBSSession/releases).

- **Windows** — `blitz-session-stats-…-windows-x64-installer.exe`. Перед установкой закройте
  OBS. Если SmartScreen предупредит: «Подробнее» → «Выполнить в любом случае».
- **macOS** — `blitz-session-stats-…-macos-universal.pkg`. Если macOS не даёт открыть:
  «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».

## Настройка

1. Получите ключ в мобильном приложении и скопируйте его.
2. OBS → **Сервис → Blitz Session Stats…**: вставьте ключ, выберите регион, период и язык.
3. В сцене: **+** → **Blitz Session Stats**. Оформление — в свойствах источника.
   Для другого аккаунта: **+** → **Blitz Session Stats — аккаунт**, укажите его ID.

Версия плагина видна в окне настроек и в свойствах источника.

## Сборка из исходников

Нужны CMake 3.28+ и Xcode (macOS) или Visual Studio 2022 (Windows):

```bash
cmake --preset macos            # или windows-x64
cmake --build build_macos --config RelWithDebInfo
```

Первая настройка скачивает исходники OBS 32 и зависимости в `.deps`. Готовые сборки и
установщики собирает GitHub Actions.
